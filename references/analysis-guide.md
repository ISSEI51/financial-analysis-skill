# 分析の基準

目的は要約ではなく、**会計知識が発展途上の読者が、企業がどう売上と利益を生み、資金をどう集めて使い、どんな強みとリスクを持つかを理解できる資料**を作ること。説明は平易に、分析は専門的かつ論理的に行う。

## 1. 分析の3階層（すべての分析で区別する）

| 表記 | 意味 | 書き方 |
|---|---|---|
| **【事実】** | 公開資料で確認できる数値・会社の公式説明 | 出典 `［S1 p.4］` を付ける |
| **【解釈】** | 複数の事実を結びつけた論理的な分析 | 根拠となる事実と推論の過程を書く。必要に応じ「確信度：高／中／低」 |
| **【仮説】** | まだ確認できないが合理的な根拠がある可能性 | 根拠と**検証方法**（次回どの数値・資料で確かめるか）を書く |

- 裏付けのない分析を書くくらいなら、その項目は省略するか「判断材料不足」と書く。
- 「売上が増えて好調」で終わらせない。**なぜ増えたか → 利益率はどう変わったか → それは続くか**まで考える。
- 将来の見通しは「会社の見通し（会社予想・中計）」と「筆者の分析」を見出しや表記で分ける。
- 投資判断（買い・売り・目標株価）は書かない。学習資料として企業の実態を理解することが目的。

確信度の目安: 高＝複数の一次資料の事実が同じ方向を示す／中＝事実は1つだが論理が明快／低＝事実が間接的で、別の説明も成り立つ。

## 2. 損益計算書（PL）の見方

- **売上が増えた理由と利益が増えた理由を分けて書く。** 売上は「数量 × 単価 × 構成（ミックス）× 為替 × 新規連結」に、利益は「売上総利益率の変化」「販管費の増減」「一時的な損益」に分解して説明する。
- 売上増加率と利益増加率が違うとき、その差を説明する（例：固定費が多い事業は売上の増減以上に利益が動く＝営業レバレッジ）。
- 一時的な損益（減損、資産売却益、為替差損益、訴訟、関税の還付など）は `one_off: true` を付けて区別し、「一時要因を除くと」の考察を加える（除いた値は筆者計算と明記）。
- 営業利益から当期純利益までの間の項目（営業外損益・特別損益・金融損益・持分法・税金・非支配株主）を省略しない。
- 実効税率が法定実効税率（日本は約30%）から大きく外れるときは理由を調べる（税効果、海外子会社、繰延税金資産の取り崩しなど）。

## 3. 貸借対照表（BS）の見方

BS は「**集めた資金（右側）を何に使っているか（左側）**」として説明する。

- 右側：負債（いずれ返すお金。うち有利子負債は利息がかかる）と純資産（株主の出資と利益の蓄積）
- 左側：すぐ現金になる流動資産、長く使う固定資産
- 資産の構成からビジネスモデルを読む（例：棚卸資産が大きい＝在庫を持って売る、有形固定資産が大きい＝設備産業、のれんが大きい＝買収で成長、販売金融債権が大きい＝ローンも提供）
- 業種特有の科目は初出時に「何か」「なぜこの会社で重要か」を説明する
- 「借入が多い＝危険」と決めつけない。営業CFでの返済能力、借入の期間、資産の換金性、業種の慣行（不動産・リース・金融は負債比率が高いのが通常）と合わせて評価する

## 4. キャッシュ・フロー（CF）の見方

- PL の利益と現金の動きの違いを重視する。黒字でも営業CFがマイナスになる例：売上債権や在庫の増加（運転資本の増加）、前受金の減少。赤字でも現金が増える例：借入・増資、資産売却、減価償却費が大きい事業。
- 営業CF ＝ 本業で稼いだ現金、投資CF ＝ 将来のための支出（設備・M&A・有価証券）、財務CF ＝ 資金の調達と返済・株主還元。
- パターンで読む：営業＋・投資−・財務−（稼いだ現金で投資と還元）、営業−・財務＋（借入で穴埋め）など。
- フリーキャッシュフローの定義を明記する（既定：営業CF＋投資CF。設備投資ベースは参考）。
- CF 未開示の四半期は「未開示」と書き、BS の現金の増減だけで CF を推定しない（現金残高の変化を【事実】として書くのはよい）。

## 5. 7つの観点

情報が足りない観点は憶測で埋めず「判断材料不足」と書き、何があれば判断できるかを書く。

| 観点 | 主な材料 | 注意 |
|---|---|---|
| ① ビジネスモデル | 何を・誰に・どう売り、どこで利益が出るか。セグメント構成、収益の型（ストック／フロー／従量） | 売上規模と利益貢献が違うセグメントに注目 |
| ② 収益性 | 売上総利益率、営業利益率、純利益率、ROE、ROA | 業種に合う指標を選ぶ。変化の原因を書く |
| ③ 成長性 | 売上・利益の成長率、セグメントの拡大、受注、会社予想、可能なら3〜5年推移 | 一時的な成長（特需・新製品の初年度・為替）と継続的な成長を区別 |
| ④ 安全性 | 自己資本比率、流動比率、有利子負債、ネットキャッシュ、営業CF | 事業特性と返済能力を考慮 |
| ⑤ 効率性 | 総資産回転率、ROIC、ROE、売上債権・在庫の回転日数 | 算出定義を明示（fin.py の formula） |
| ⑥ 将来性 | 中期経営計画、投資計画、市場成長、競争環境、経営戦略 | 会社の見通しと独自の分析を分ける |
| ⑦ リスク | 事業・財務・競争・規制・為替・技術・経営 | 重大なものだけ優先度順に。企業固有の根拠があるものに限る（有報「事業等のリスク」を参照） |

## 6. 業種で指標を変える

同じ指標だけで評価しない。業種に応じて主指標を選び、成立しない計算を強制しない。

| 業種 | 重視する指標・見方 | 当てはまらないもの |
|---|---|---|
| 銀行 | 業務純益、預貸金利回り差、経費率（OHR）、自己資本比率（規制上）、不良債権比率 | 売上総利益、流動比率 |
| 保険 | 正味収入保険料、コンバインド・レシオ、ESR、修正利益 | 一般事業会社の PL の段階利益 |
| 証券・金融サービス | 純営業収益、預り資産、ROE | 棚卸資産回転 |
| 不動産 | 販売用不動産の回転、賃貸 NOI、LTV、有利子負債/EBITDA | 「借入が多い＝危険」の短絡 |
| 製造業 | 売上総利益率、設備投資と減価償却、在庫回転、受注残、為替感応度 | |
| SaaS・サブスク | ARR/MRR、売上継続率（NRR）、解約率、ストック売上比率、S&M 比率 | 赤字だけを理由に低評価しない（投資段階か確認） |
| 小売・外食 | 既存店売上高、客数×客単価、出店数、在庫回転、店舗利益率 | |
| 商社・持株会社 | 持分法損益、セグメント別純利益、投資の入替え | 売上高（総額／純額表示の違い） |
| 電力・ガス・インフラ | 燃料費調整の期ずれ、設備投資、有利子負債、規制料金 | 単年度の利益率だけで判断 |
| ゲーム・エンタメ | タイトル・ハードのサイクル、販売本数、デジタル比率、在庫 | 単年の成長率だけで判断（サイクル要因） |

## 7. 会計基準と期間の注意

- **IFRS**：経常利益がない。営業利益に「その他の収益・費用」（減損や売却益を含み得る）が入る。のれんを償却しない。リースを原則オンバランス（使用権資産・リース負債）。
- **日本基準**：経常利益がある。特別損益で一時的な損益を区分する。のれんを償却する。
- **米国基準**：営業利益の範囲や表示科目が異なる。
- 会計基準が変わった期の前後は単純比較しない（`fin.py history` が警告する）。
- PL・CF は**期間の合計（フロー）**、BS は**特定日の残高（ストック）**。四半期の ROE などは年換算の参考値として扱い、季節性があれば注記する。
- 四半期累計値と単独四半期値を区別する。単独値は `fin.py quarter` で差分を出し、同じ基準・範囲・比較可能な期間であることを確認する（遡及修正があれば修正後の前四半期値を使う）。
- 決算修正・会計方針の変更・組替えは `notes` に書き、本文でも触れる。

## 8. 決算間の比較（履歴がある場合）

同じ企業の過去ノート・データがあれば `fin.py history <data_dir>` を実行し、次を検討する。

- 前回決算から何が変わったか（売上・利益率・財務安全性）
- 前回の `concerns`（懸念点）は改善したか
- 以前の会社予想と実績の差（`forecast_vs_actual`）。予想の保守性・楽観性の傾向
- 経営戦略・会社予想の変更
- 比較できない数値（基準変更・期の種類の違い・連結範囲の大幅変更）は比較しない

## 9. 書き方

- 専門用語は初出時に一文で説明する（例：「売上総利益（粗利）：売上高から製品を作る・仕入れる費用（売上原価）を引いた利益」）。用語説明は `> [!note] 用語：…` の callout にまとめてよい。
- 数字の羅列を避け、表と図に任せる。本文は**因果関係**（何が起きた → なぜ → 何を意味する）を書く。
- 金額は本文では億円（大きい会社）で、表は原資料の単位で示す。換算した値は丸め方を明記する。
- 比喩・誇張・俗語を使わない。断定できないことは断定しない。
